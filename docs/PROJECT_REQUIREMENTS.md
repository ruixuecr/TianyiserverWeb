# 项目介绍与需求

更新日期：2026-10-29。mapapi 为地图基线，当前云端实现位于 codex/encore-theme-elements。

## 定位与范围

项目名称 TianyiserverWeb，页面品牌为“江城 Encore”。面向赴武汉看演唱会并顺路游玩的访客，提供少量精选打卡点、地点图片、活动宣传和通知。最初预估十几个点位，当前确定 7 个。当前不包含后台管理、数据库、注册登录、购票或支付。

## 页面与交互

| 页面 | 已确认需求与当前表现 |

## 地图视觉约定

- 参考用户提供的俯瞰构图，但不采用最初参考图的深蓝科技大屏配色。
- mapapi 基线为浅色、绿色与米白色界面；当前主题分支按用户要求统一为首页的蓝白、淡金配色，地图原有绿色图钉和名称标签保持。真实底图使用用户配置的高德自定义样式。
- 早期曾保留其他页面的 2D/3D 切换；后续用户选择武汉轮廓方案并要求去掉平面效果。当前共享地图均为 3D，不把早期要求误当成现行要求。
- 初始 zoom 11、中心 [114.305, 30.56]，接近用户截图范围；不同容器尺寸下范围会不同，并非逐像素复刻截图。
- 首次加载不自动适配整个行政区；“查看全城”仍可显示整个武汉轮廓。
- 用户要求隐藏铁路、地铁、高速等干扰信息；主要通过高德样式编辑器处理，SDK 接入样式 ID。样式服务返回成功不等于证明编辑器最新修改已发布。

## 图片与内容

图片最初来自用户本机 E:/TopPicture，所需文件已复制进 public/images/spots/ 并提交 Git，不要求云端访问该本机目录。

featuredImage 控制独立大图和详情大图，thumbnail 控制小图；无小图可使用 Art 示意插画。奥体目前没有独立照片。巴公房子关联图是用户给定对应文件的宣传海报，不应擅自换图。博物馆改名后沿用原图片资源，是否需要更换成新的对应图片尚待后续确认。

用户反馈图片加载慢后，主题分支已将首页、地点及装饰图片接入 Next.js 图片优化：按显示尺寸和设备像素比加载 WebP，首页主视觉优先加载，地图大图在选中后加载，详情下方图片与小装饰延迟加载。地点照片保留原始宽高比，原始素材仍保存在仓库，未裁切或替换。

## 时光主题工作分支

用户要求结合本次提供的角色、钢琴、蓝白花簇、飘带、音符及环形参考素材，引入组件库，并在新分支增加主题元素。实现位于 codex/encore-theme-elements，基于 mapapi 的 0d4bc49；main 与 mapapi 分支指针保持原状。

最初“时间”按字面解释为时光流转；用户后续明确要求放大时钟并置于钢琴角色图后方，当前继续沿用时光主题与所提供的音乐素材。

- 首页保留原大标题和下方城市地图，主视觉改为用户提供的钢琴角色图；增加蓝金飘带、花瓣、细线钟盘和无限回放意象，不恢复旧统计或推荐卡片区。
- 全站导航增加“武汉此刻”：显示 Asia/Shanghai 时区的真实时间，点击展开模拟钟面、数字时间和日期，无演出倒计时或虚构活动日期。
- 动效开关控制装饰花瓣和钟盘刻度旋转，偏好保存在当前浏览器；系统减少动态效果时优先停用装饰动效，实时钟仍正常报时。
- 活动和通知页增加淡色花簇，地图侧栏及页脚增加小型音乐装饰；地图标签、相机、地点数据和地点图片展示规则保持既有实现。
- 组件库选用 Radix UI Popover / Switch，由项目自行提供蓝白、淡金配色样式；原 Next.js、React 等依赖版本未升级。
- 用户随后要求其他页面配色与首页一致：探索地图、地点详情、活动及活动详情、通知及通知详情共用蓝灰文字、蓝色操作按钮、浅蓝卡片和淡金点缀；悬停、选中与手机端状态同步统一。站内 SVG 插画使用对应蓝金色板，用户提供的图片保留原色。
